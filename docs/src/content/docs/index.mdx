## The tools

<CardGrid>
  <Card title="graft" icon="pencil">
    Lets an agent write to GitHub as a GitHub App. Commits land Verified, your git hooks still run, and CODEOWNERS decides what needs a human.
  </Card>
  <Card title="cambium" icon="random">
    The scheduler. Reads the `q:*` labels every tick, runs headless Claude Code workers in their own worktrees, and moves each issue through triage, work, review and release.
  </Card>
  <Card title="mycelium" icon="comment-alt">
    Intake. Turns Discord posts, App Store and Google Play reviews, TestFlight feedback and crash reports into deduplicated `q:intake` issues.
  </Card>
  <Card title="canopy" icon="laptop">
    A local, read-only page over the queues: what needs you, what is running, and how each issue moved.
  </Card>
  <Card title="canker and deadwood" icon="approve-check">
    Quality gates for agent-written code: complex untested functions, stray markdown and comment bloat.
  </Card>
  <Card title="oakgreen" icon="setting">
    One CLI to check a machine, set up what is missing and run the services.
  </Card>
</CardGrid>
