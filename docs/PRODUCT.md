# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Engineers and teams who set up and run the oakgreen stack (graft, cambium, mycelium, canopy, canker, deadwood, the `oakgreen` CLI) against their own GitHub repositories. They read during setup, while debugging a stuck queue, or when looking up a flag.
- Clients and prospects of Oak Green Cloud Consulting evaluating the tooling. The docs double as a shop window for the consultancy's craft.

## Product Purpose

oakgreen runs coding agents against a GitHub repository with GitHub as the source of truth. Every agent write is a Verified commit made by a GitHub App, every queue is a label, and a human approves what matters (CODEOWNERS decides). The docs site (docs.oakgreen.cc) teaches, guides, and records the facts of that stack.

## Positioning

GitHub is the boundary: no side database, no bespoke dashboard as the record. State lives in labels, commits and PRs a team already reads.

## Operating Context

- Docs follow Diátaxis: tutorials, how-to guides, reference, explanation (`docs/AGENTS.md`).
- Built with Astro Starlight, deployed to GitHub Pages at docs.oakgreen.cc.
- British spelling, sentence-case headings, short pages.

## Brand Commitments

- Parent brand: Oak Green Cloud Consulting, oakgreen.cc. Forest-black ground `#0b190f`, deep green `#173620`, brand green `#3c9057`.
- Mark: the concentric tree-ring logo (open rings with a radial notch), stroked, round caps.
- Wordmark voice: light-weight sans, wide-tracked uppercase.
- Playful side: slow-turning logo with orbiting objects (earth, rocket, satellite, teapot, UFO, sputnik). In the docs this lives on the home page only; reading pages stay calm.
- Theme: dark is the default; a light mode stays available.

## Evidence on Hand

- Logo SVG geometry from oakgreen.cc (reproduced in `docs/public/favicon.svg`).
- No customer logos, testimonials or metrics exist; none may be invented.

## Product Principles

1. GitHub is the record; docs never contradict the package READMEs.
2. Short beats complete: the reader finds the fact fast.
3. Humans approve what matters; the docs speak to humans, not agents.
